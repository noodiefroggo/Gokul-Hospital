# Gokul Hospital: brand & website proposal

Concept proposal for Gokul Hospital, Dwarka Mor, New Delhi. It's a static site with no build step needed to view it.

- `index.html`: proposal overview (the site root)
- `logo/`: logo concepts, final files and presentation board (`logo/index.html`)
- `home/brand.html`: home page A, light brand theme
- `home/dark.html`: home page B, dark theme
- `ads/`: social posts and Meta ads (`ads/index.html` gallery, `ads/png/` exports, `ads/ad-copy.md`)
- `BRAND_BRIEF.md`: shared brief, palette and type

To regenerate the proposal after editing `proposal/src.html` or the logo, run `node proposal/_build/build.js`.
To refresh the screenshots, run `sh proposal/_build/shots.sh`.

Photos are stock images from Pexels and Unsplash (see `home/img/CREDITS.md`). Review text is paraphrased, and doctor profiles other than Dr. Rohita are placeholders.
